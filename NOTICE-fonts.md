# OLED fonts

* Title font: glyphs rendered from **Aileron Regular** by Sora Sagano,
  licensed under the SIL Open Font License, Version 1.1
  (https://openfontlicense.org). The font is bundled with Pillow; the bitmap
  table in `firmware/ui_fonts.h` is generated by `tools/gen_fonts.py`.
* Clock font: the 5x7 font of pico_ssd1306 (MIT, see libs/pico_ssd1306/LICENSE).
* Bar font: 3x5 pixel font drawn for this project (GPL-2.0-only with the firmware).
